# NEXUS PRODUCT PRINCIPLES

1. Structure beats verbosity.
2. Constraints are first-class data.
3. Uncertainty must be visible.
4. Different solutions must actually be different.
5. Conclusions need traceable reasons.
6. AI proposes; validation and the user remain in the loop.
7. A small believable prototype beats a giant fake product.
8. Every interface element must earn its space.
9. Mobile is a primary environment.
10. Reliability beats spectacle.
11. Failed AI requests must not destroy user work.
12. Prefer explainable state transitions over magic.
