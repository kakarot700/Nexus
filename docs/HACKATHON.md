# NEXUS HACKATHON MODE

The final submission must follow the official challenge rules.

Before building the hackathon-specific layer, verify:
- theme
- eligibility
- pre-existing-work rules
- allowed tools/services
- submission format
- judging criteria
- deadline/timezone
- demo requirements

Keep the NEXUS engine reusable, but make the final problem, constraints, solution, and prototype clearly relevant to the announced theme.

Never misrepresent pre-hackathon work as work created during the event.
