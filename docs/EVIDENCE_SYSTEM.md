# NEXUS EVIDENCE SYSTEM

USER_PROVIDED: directly supplied by the user.
DERIVED: reasonably inferred from supplied information.
PROPOSED: generated by NEXUS.
UNVERIFIED: requires verification.

Important evidence states should be visible in the UI.

Never silently upgrade:
UNVERIFIED → FACT
PROPOSED → FACT

Important decisions should reference the evidence and constraints that produced them
using IDs that resolve to existing source objects. Never invent references; when no
supporting object exists, expose the uncertainty instead.
