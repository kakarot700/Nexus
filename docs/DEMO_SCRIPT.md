# NEXUS DEMO SCRIPT

Target: 2–3 minutes.

0:00–0:15: Introduce a concrete problem and thesis: "Most AI systems answer problems. NEXUS works through them."

0:15–0:35: Enter the problem.

0:35–0:55: Show the Problem Map: stakeholders, goals, evidence, unknowns, constraints.

0:55–1:15: Generate genuinely different approaches.

1:15–1:35: Stress-test and evaluate them against constraints.

1:35–1:55: Select a direction and generate the prototype.

1:55–2:15: Interact with the prototype.

2:15–2:30: Show Decision Trail and uncertainty labels.

Closing idea: "NEXUS doesn't just generate ideas. It turns constraints into a path toward a solution."

Never demo an untested feature. Keep a deterministic fallback/demo scenario if live AI fails.
