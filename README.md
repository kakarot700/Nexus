# NEXUS GITHUB-READY AI CONTEXT PACK

This pack contains the permanent product, design, engineering, AI, and quality context for NEXUS.

## Installation
This repository is the unpacked NEXUS context pack. `AGENTS.md` is already at its root.

To apply the pack to another NEXUS repository, copy the desired contents of this
repository directly into that repository's root; do not place them under a nested
`nexus-ai-context/` directory. This repository contains documentation only: it does
not include application source code or a distributable archive.

## Agent instruction
Read `AGENTS.md` and the relevant project documentation before changing code. Inspect the existing implementation first. Follow the repository's product, design, architecture, and engineering rules. Implement the smallest coherent change, then validate it.

## Source-of-truth hierarchy
1. Official hackathon rules
2. Product requirements
3. Design system
4. Architecture decisions
5. Engineering standards
6. Task-specific instructions

If a lower-level instruction conflicts with an official rule, follow the official rule.

This pack is documentation, not application source code.
