# NEXUS UI REVIEW

Render the actual application. Do not review only source code.

Viewports:
- 360 × 800
- 390 × 844
- 768 × 1024
- 1280 × 800

Check:
- first impression
- primary action
- hierarchy
- typography
- spacing
- alignment
- density
- borders
- radius
- color
- icon consistency
- loading/error/empty states
- primary interaction
- long AI responses
- slow network
- mobile keyboard

Flag purple gradients, excessive rounded rectangles, unexplained card grids, decorative statistics, giant empty heroes, random illustrations, glass effects, inconsistent icons, excessive animation, and cramped mobile layouts.

Question: Does every visible decision look deliberate?
