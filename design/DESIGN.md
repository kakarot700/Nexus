# NEXUS DESIGN SYSTEM

NEXUS should feel like a sophisticated instrument for thinking.

Priorities:
1. hierarchy
2. clarity
3. information density
4. spatial rhythm
5. typography
6. interaction quality

Use editorial typography, scientific-instrument clarity, restrained premium interaction design, and structured information visualization.

## Layout
Spacing scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80px.

Do not wrap every element in a card.

Cards represent real conceptual objects: solution, constraint, evidence, prototype, or decision.

Use subtle borders and restrained shadows.

Color communicates meaning, not decoration.

Motion explains state change.

Use one coherent icon family.

## Forbidden generic AI patterns
- purple AI gradient
- glowing orb
- robot illustration
- sparkle decoration
- "AI POWERED" badge
- excessive glassmorphism
- excessive pill controls
- giant gradient hero
- default dashboard sidebar

## Product identity
The Solution Graph is central:
Problem → Constraints → Possible solutions → Evaluation → Selected direction → Prototype
